层一：流场背景 canvas 2d

向量场由四组不同频率的正弦叠加而成，成本几乎为零；粒子每帧按场方向前进，并把当前位置以低透明度画回画布形成拖尾。画布尺寸跟随 devicePixelRatio，避免高分屏发虚。

层二：渐变位移标题 CSS background-position

文字用 background-clip:text 裁出渐变，再让渐变自身缓慢移动。比逐字动画更省，也不会打断阅读节奏。

层三：数据流带 canvas 2d

一条随时间推进的横向流带，把"正在处理"这件事画出来。它是给运维看板用的：把代理的实时计数接进来即可。
