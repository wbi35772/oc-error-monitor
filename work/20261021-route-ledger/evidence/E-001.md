# E-001 · 设置只存内存，重启即回出厂值

**severity**: high

## 观察

重启电脑后，生产 8788 的 `force_route` 仍是 `direct`。但代码里没有任何持久化：

```
$ Select-String -Path "$rt\*.py","$rt\*.ps1","$rt\*.json" -Pattern 'force_route'
  retry_proxy.py:162: "force_route": None,  # None | "proxy" | "direct"
  retry_proxy.py:536: if "force_route" in data:
  retry_proxy.py:537:     v = data["force_route"]
  retry_proxy.py:538:     SETTINGS["force_route"] = v if v in ("proxy", "direct") else None
```

runtime 目录里只有 `deployed.json` / `retry_proxy.log.jsonl` / `*.lock` / `*.vbs`，**没有 settings 文件**。

对照实验：置空 → 读回 → 置回 direct，三步全部即时生效，说明 `SETTINGS` 是内存字面量。

```
POST /__control {"action":"set","force_route":null}   -> ok=True route=''
GET  /__stats                                          -> route=''
POST /__control {"action":"set","force_route":"direct"} -> ok=True route=direct
```

## 影响

`force_route=direct` 是当时把 429 从 43 次压到 0 的关键（direct 92.5% / 0 次 429，proxy 67.9% / 43 次 429）。它只活在内存里，重启后流量自动回到 CF 通道，429 全部回来，而日志里没有任何线索说明为什么。

## 结论

设置必须落盘。修复见 `1ea68f4`。

## 复现

```powershell
$rt = Join-Path $env:USERPROFILE '.config\opencode\oc-error-monitor-v1.1.0'
Get-ChildItem $rt -File | Where-Object { $_.Name -match 'settings|state' }   # 无输出
Select-String -Path "$rt\*.py" -Pattern 'force_route'
```
