# E-002 · route 整块落盘会把默认值冻死

**severity**: high

## 观察

第一版持久化把 `ROUTE` 整块写进 `settings.json`。随后我改了 `DEFAULT_ROUTE["rotate_on"]` 的默认值（从自创的 `AUTH_IP_REPUTATION,RATE_LIMIT,CONNECT,TIMEOUT` 改成对齐 `controller.SWITCH_CLASSES` 的 `NET_CONNECT,NET_DNS,NET_STREAM,NET_TIMEOUT`），重启后运行实例报的还是旧值：

```
route.rotate_on=AUTH_IP_REPUTATION,RATE_LIMIT,CONNECT,TIMEOUT     # 改了默认值之后
```

原因：文件里存着整块 route，加载时它整块覆盖默认值。**默认值改了，永远到不了已经有文件的实例**——除非用户手动去改那个文件。

## 修复

只落盘与默认不同的部分（`_route_diff`）：

```python
def _route_diff(node, base):
    """Only what differs from the defaults. ..."""
```

落盘结果：

```json
{
  "schema": 1,
  "settings": { "attempts": 8, "force_route": "direct", ... },
  "route": {},
  "saved_at": "2026-10-21T10:27:29",
  "saved_by": "control:set"
}
```

`route` 是空对象——因为此刻确实没有一项偏离默认。改一个值就只出现那一个键：

```json
"route": { "select": { "cooldown_s": 7 } }
```

## 回归测试

`test_l0_settings.py`：

- `test_only_differences_are_stored`
- `test_a_changed_default_reaches_an_existing_file`：文件里已有一个 `settings.json` 时，改默认值后 `_load_settings()` 拿到的是新默认值。

## 复现

```powershell
python -c "import sys; sys.path.insert(0,'.'); import retry_proxy as r; print(r._route_diff(r.ROUTE, r.DEFAULT_ROUTE))"
```
