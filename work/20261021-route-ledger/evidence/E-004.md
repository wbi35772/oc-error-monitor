# E-004 · 账本吃日志词汇，最该轮换的一类从不触发

**severity**: high

## 观察

真机请求 8899，4 次尝试全部失败：

```
{"ts": "...", "method": "GET", "path": "/models",
 "attempts": ["ERR:URLError", "ERR:URLError", "ERR:URLError", "ERR:URLError"],
 "detail": [{"cls": "ERR:URLError",
             "err": "<urlopen error [SSL: UNEXPECTED_EOF_WHILE_READING] EOF occurred in violation of protocol (_ssl.c:1010)>"}]}
```

账本里四个 `IPv6优选` 成员各失败一次（衰减值 0.997062 / 0.997787 / 0.998672 / 0.999605），**但没有一个进入冷却**。

## 根因：两套词汇

| 层 | 词汇来源 | 例 |
|---|---|---|
| 日志 | `classify(status, body)` | `IP_REP` / `RATE` / `5XX` / `ERR:URLError` |
| 策略 | `controller.SWITCH_CLASSES` | `NET_DNS` / `NET_CONNECT` / `NET_STREAM` / `NET_TIMEOUT` |

`ERR:URLError` 两边都不属于，于是**最该触发轮换的那一类，恰恰从不触发**。

## 修复

新增翻译层 `policy_class(cls, err=None)`。ERR 分支把异常类名与消息归一化成 token 流再判定——因为异常名是驼峰（`ConnectionResetError`）而消息是散文（`connection reset`），不归一化就得写两条规则：

```python
text = re.sub(r"[^a-z0-9]", "", ("%s %s" % (cls[4:], err or "")).lower())
if "getaddrinfo" in text or ...:            return "NET_DNS"
if "timeout" in text or "timedout" in text: return "NET_TIMEOUT"
if "certificate" in text or ...:            return "NET_TLS"
if "connectionrefused" in text or ...:      return "NET_CONNECT"
if "ssl" in text or "eof" in text or ...:   return "NET_STREAM"
return cls        # 认不出来就原样返回：只记账，永不轮换
```

最后一行是安全默认：错一次轮换会动所有人的出口 IP。

```
冷却后 -> n2 strategy:least_fail current=n2
```
