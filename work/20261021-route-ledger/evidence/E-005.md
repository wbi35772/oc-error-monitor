# E-005 · 零数据时 DIRECT 抢平手，安全网静默接管整个池

**severity**: medium

## 观察

首次调用策略选择器，零数据：

```
pick -> DIRECT | strategy:least_fail | direct True
```

没有任何成员有记录，所有健康度相同（`ok_rate` 一律 0.5），而排序键里成员名是次级键——`DIRECT` 以字母 D 开头，排在 emoji 名前面，于是**每一次平手都由 DIRECT 赢**。

DIRECT 是安全网（mihomo 挂了时的兜底），不是偏好。它在零数据时接管整个池，等于代理看起来在工作，实际一个节点都没用。

## 修复

策略外面包一层稳定排序，把 DIRECT 压到最后：

```python
def _rank(order_fn):
    """DIRECT is the safety net, not a preference. ..."""
    def run(cands, current):
        return sorted(order_fn(cands, current), key=lambda m: bool(m.get("direct")))
    return run
```

用 `sorted` 而非 `sort` 是因为它稳定：策略自己的顺序不被破坏，DIRECT 只在完全并列时被压到后面。
